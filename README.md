# C++ Practice

A collection of C++ programs and exercises written while practicing core language concepts, data structures, and algorithms.

## 🚀 Getting Started

### Prerequisites
- A C++ compiler (GCC/G++, Clang, or MSVC)
- (Optional) `make` or `cmake` if using build files

### Compiling a single file
```bash
g++ -std=c++17 -o output filename.cpp
./output
```

### Compiling with warnings enabled (recommended for practice)
```bash
g++ -std=c++17 -Wall -Wextra -o output filename.cpp
```

## 📚 Topics Covered

- [ ] C++ basics (variables, loops, functions, pointers)
- [ ] Object-Oriented Programming
- [ ] Data Structures (arrays, linked lists, stacks, queues, trees, graphs)
- [ ] Algorithms (sorting, searching, recursion, dynamic programming)
- [ ] STL (vectors, maps, sets, iterators)
- [ ] Problem-solving practice

## 🧠 Purpose

This repository is meant purely for self-practice and learning — trying out new concepts, revisiting fundamentals, and solving problems to build stronger C++ skills.
